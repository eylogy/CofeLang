- **CSS3** for styling (`styles.css`)
- **Vercel** for hosting
- **Prettier** for code formatting (`.prettierrc`)

## How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   ```
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.

No installation or build step is needed.

## Feedback

Feel free to give feedback or suggest improvements on our website!

### How to Give Feedback

1. Go to the **Issues** tab at the top of this repository.
2. Click **New issue**.
3. Write a short title (for example: `Suggestion for the products page`).
4. In the description, mention the page or file name and explain your feedback.
5. Click **Submit new issue**.
